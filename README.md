# Powder Benchmark

Benchmarking modern computer vision architectures on the DeCost-Holm synthetic powder dataset (2016).

## Goal
Compare ResNet, EfficientNet, ConvNeXt, ViT, Swin, and DINOv2 against the BOVW + SVM baseline (89% accuracy) reported in DeCost & Holm 2016.

## Dataset
- 2,048 synthetic SEM images of powder materials
- 8 particle size distributions (256 images each)
- Source: https://data.mendeley.com/datasets/tj4syyj9mr/1
